# ledmatrix
I built this 8x8 LED matrix just because I liked the whole idea. It's a fun project to assemble with the step-by-step guide. Pair this little screen with the firmware and you can do all sorts of cool stuff! It can show live weather icons, make your emojis play animations, or scroll custom text across the grid.
